# Wizardry Korean Companion

도스(PC)판 **위저드리 1~5편**을 DOSBox에서 한글로 즐길 수 있게 해 주는 비공식 팬 제작 프로그램입니다.
게임 화면 위에 한글 번역을 덮어 보여 주고, 옆 창(컴패니언)에서 미궁 지도·주문 목록·아이템 도감을 볼 수 있습니다.
게임 파일은 고치지 않습니다.

> 이 프로그램은 Wizardry의 권리자와 관계가 없으며, 권리자가 승인하거나 지원하지 않습니다.
> 게임 파일은 들어 있지 않습니다. 정품 게임이 필요합니다.

## 주요 기능

- **한글 오버레이**: 게임 화면의 메뉴, 메시지, 전투 문장, 몬스터·아이템 이름을 한글로 덮어 보여 줍니다.
- **미궁 지도 (F1)**: 게임 디스크에서 미궁을 읽어 그립니다. 파티 위치와 방향, 계단·함정·이동 칸 같은 특수 칸, 미궁에 남은 시체를 표시합니다. 가 본 칸만 보이는 안개(켜고 끌 수 있음)와 탐험 기록 저장을 지원합니다.
- **주문 목록 (F2)**: 마법사·성직자 주문의 효과, 대상, 피해 주사위를 한글로 정리했습니다.
- **아이템 도감 (F3)**: 게임 디스크에서 아이템 표를 읽어 가격, 장비 가능 직업, AC, 피해, 특수 능력 등을 보여 줍니다. 정렬할 수 있습니다.
- **스탯 보호**: 레벨업이나 나이 때문에 능력치가 떨어지는 것을 막습니다.
- **편의 기능**: 체력 회복, 죽은 동료 부활, 미감정 아이템 감정, 캐릭터 만들기 자동 굴림.

## 준비물

- Windows 10/11
- [DOSBox 0.74-3](https://www.dosbox.com/)
- 위저드리 1~5편 게임 파일: **Ultimate Wizardry Archives**(Interplay, 1998) 판본이 필요합니다. 아래 "필요한 게임 판본"을 보세요.

## 필요한 게임 판본

이 프로그램은 **Interplay가 1998년에 낸 합본 CD-ROM *Ultimate Wizardry Archives*에 실린 1~5편 도스판**에서 동작합니다.

위저드리 폴더에 아래 파일이 한곳에 있으면 맞는 판본입니다.

| 편 | 실행 파일 | 시나리오 디스크 (크기) |
|---|---|---|
| 1편 Proving Grounds of the Mad Overlord | `WIZ1.COM` | `WIZ1.DSK` (327,680바이트) |
| 2편 The Knight of Diamonds | `WIZ2.COM` | `WIZ2.DSK` (327,680바이트) |
| 3편 Legacy of Llylgamyn | `WIZ3.COM` | `WIZ3.DSK` (327,680바이트) |
| 4편 The Return of Werdna | `WIZ4.COM` | `WIZ4.DSK` (327,680바이트) |
| 5편 Heart of the Maelstrom | `WIZ5.COM` | `WIZ5.DSK` (655,360바이트) |

게임을 저장하면 같은 폴더에 `SAVE1.DSK`~`SAVE5.DSK`가 생깁니다. 이 프로그램은 게임 파일을 배포하지 않으며, 구하는 곳도 안내하지 않습니다.

## 설치와 실행

1. [Releases](../../releases)에서 최신 zip을 받아 원하는 폴더에 풉니다. 설치는 필요 없습니다.
2. `Wizardry_Korean_Companion.exe`를 실행합니다.
3. 컴패니언 창에서 **DOSBox**에 `DOSBox.exe`를, **위저드리 폴더**에 게임 파일이 있는 폴더를 **찾기**로 고릅니다.
   - DOSBox를 기본 위치(Program Files)에 설치했거나, exe를 위저드리 폴더(또는 그 위·아래 폴더)에 두었다면 자동으로 채워집니다.
4. 몇 편을 할지 고르고 **게임 실행**을 누르면 DOSBox가 큰 창으로 뜨고 자동으로 연결됩니다.
5. **오버레이** 버튼을 누르면 게임 화면 위에 한글이 나옵니다. 다시 누르면 컴패니언으로 돌아갑니다.

처음 실행하면 exe 옆에 설정 파일(`wiz_overlay_settings.json`, `wiz_dosbox.conf`)과 편별 탐험 기록(`wiz1_explored.json`~`wiz5_explored.json`)이 생깁니다.

## 게임 메모리를 고치는 기능

아래 기능은 실행 중인 게임 메모리의 파티 기록을 직접 고칩니다. 디스크 파일은 고치지 않지만, 게임이 저장하면 바뀐 값이 그대로 남습니다. 원래 규칙대로 하고 싶으면 쓰지 마세요.

- **스탯 보호** (기본으로 켜짐): 파티원의 능력치가 내려가는 순간 바로 전 값으로 되돌립니다. 레벨업 화면에 `→ 스텟 보호`가 붙으면 되돌린 것입니다.
- **체력 회복, 죽은 동료 부활, 미감정 아이템 감정**: 성·마을에 있을 때만 누를 수 있습니다. 소실(LOST)된 캐릭터는 되살리지 않습니다.
- **캐릭터 만들기**: 목표 보너스가 나올 때까지 키를 대신 눌러 다시 굴립니다. 호빗은 지능에 점수를 넣고 마법사로 굴립니다.

## 알아 둘 점

- DOSBox 0.74는 전체 화면(Alt+Enter)에서 마우스를 붙잡아 오버레이 버튼을 누를 수 없습니다. 큰 창 모드로 쓰거나 단축키를 쓰세요.
- 서명되지 않은 실행 파일이라 Windows SmartScreen이 경고할 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 오류가 나면 exe 옆에 `wiz_overlay_error.log`가 생깁니다. 문제를 알려 주실 때 함께 보내 주세요.

## 소스에서 실행하기

Python 3.13과 Pillow가 필요합니다. 소스는 `src` 폴더에 있습니다.

```bash
pip install pillow pyinstaller
cd src
python wiz_overlay.py
```

배포용 exe는 `src`에서 `python build.py --release`로 `src\release\`에 만듭니다.

## 저작권과 라이선스

- Wizardry는 해당 권리자의 상표이며, 게임과 그 내용(문장, 지도, 그림)의 저작권은 권리자에게 있습니다. 이 프로그램은 무료로 배포하는 비공식 팬 제작물입니다.
- 게임 파일과 지도 데이터는 들어 있지 않습니다. 지도와 아이템 정보는 실행할 때 사용자의 게임 디스크에서 읽습니다. 화면 문장(네 낱말 이상)은 원문 대신 원문의 해시값으로 찾아 한글로 바꿉니다. 짧은 메뉴 낱말과 몬스터·아이템 이름은 화면 글자와 맞추려고 영문을 그대로 담고 있습니다.
- 권리자의 요청이 있으면 배포를 즉시 중단합니다.
- 한글 글꼴: [Neo둥근모](https://github.com/neodgm/neodgm) (SIL Open Font License 1.1, `src/docs/release/NeoDunggeunmo_LICENSE.txt`).
- 함께 묶인 오픈소스(Python, Tcl/Tk, Pillow, PyInstaller)는 `src/docs/release/THIRD_PARTY_NOTICES.txt`를 보세요.
- 게임 메모리 배치는 WhereAreWe 등 공개된 조사 자료를 참고했습니다.
