Wizardry Korean Companion 1.0.2
===============================

위저드리 한글 오버레이·컴패니언

DOSBox에서 도는 PC(도스)판 위저드리 1~5편(CGA) 화면 위에 한글 번역을 덮어 보여 주는
비공식 팬 제작 프로그램입니다. 게임 파일은 고치지 않습니다.

이 프로그램은 Wizardry의 권리자와 관계가 없으며, 권리자가 승인하거나 지원하지 않습니다.

준비물
------
- DOSBox 0.74-3
- 위저드리 1~5편 게임 파일. Interplay가 1998년에 낸 합본 CD-ROM
  "Ultimate Wizardry Archives"에 실린 도스판에서 동작합니다. 한 폴더에 WIZ1.COM~WIZ5.COM과
  WIZ1.DSK~WIZ5.DSK(1~4편 327,680바이트, 5편 655,360바이트)가 있으면 맞는 판본입니다.
  게임 파일은 들어 있지 않으며, 구하는 곳도 안내하지 않습니다.

실행
----
1. Wizardry_Korean_Companion.exe를 실행합니다(설치 필요 없음).
2. 컴패니언 창의 "DOSBox"에 DOSBox.exe, "위저드리 폴더"에 WIZ1.COM이 있는 폴더를
   "찾기"로 고릅니다. 지도는 이 폴더의 WIZ1.DSK에서 읽습니다.
   - DOSBox를 기본 위치(Program Files)에 설치했거나, 이 exe를 위저드리 폴더(또는 그 위·
     아래 폴더)에 두었다면 자동으로 채워집니다.
3. 몇 편을 할지 고르고 "게임 실행"을 누르면 DOSBox가 큰 창으로 뜨고 자동으로 연결됩니다.
4. "오버레이"를 누르면 게임 화면 위에 한글이 나옵니다.

단축키 (DOSBox나 이 프로그램 창이 맨 앞일 때)
--------------------------------------------
- F1        : 지도 열기/닫기
- F2        : 주문 목록 열기/닫기
- F3        : 아이템 도감 열기/닫기

스탯 보호
---------
위저드리는 레벨이 오를 때 능력치(힘, 지능, 신앙, 생명력, 민첩, 행운)가 오르기도 하지만
떨어지기도 합니다. 스탯 보호는 파티원의 능력치가 떨어지는 것을 막아 주는 기능입니다.

- 컴패니언의 "스탯 보호: 켜짐 / 꺼짐" 버튼으로 켜고 끕니다. 처음에는 켜져 있습니다.
- 켜져 있으면 파티원의 능력치가 내려가는 순간 바로 전 값으로 되돌립니다.
  오른 능력치는 그대로 둡니다.
- 레벨업 화면의 "YOU LOST ..." 줄 옆에 "→ 스텟 보호"가 붙으면 그 능력치를 되돌린 것입니다.
- 레벨업뿐 아니라 레벨이 그대로일 때 능력치가 내려가는 경우(예: 여관에서 쉬며 나이를
  먹을 때)도 되돌립니다.
- 지금 파티에 들어 있는 캐릭터만 대상입니다. 1~3편에서 동작합니다.
- 게임 메모리의 캐릭터 능력치 값만 고칩니다. 이 값은 게임이 저장할 때 그대로 남으니,
  원래 규칙대로 하고 싶으면 꺼 두세요.

게임 메모리를 고치는 버튼
------------------------
스탯 보호 말고도 아래 버튼은 게임 메모리의 파티 기록을 직접 고칩니다. 성·마을에
있을 때만 눌리고, 게임이 저장하면 그대로 남습니다. 디스크 파일은 고치지 않습니다.
- 체력 회복, 죽은 동료 부활(사망·재. 소실은 제외): 1~3편, 5편
- 미감정 아이템 감정: 1~3편, 5편
- 캐릭터 만들기: 원하는 보너스가 나올 때까지 키를 대신 눌러 다시 굴립니다(1·5편).
  메모리는 키보드 입력 버퍼에 키 하나씩만 씁니다.

알아 둘 점
----------
- DOSBox 0.74는 전체 화면(Alt+Enter)에서 마우스를 붙잡아 오버레이 버튼을 누를 수
  없습니다. 큰 창 모드로 쓰거나 단축키를 쓰세요.
- 처음 실행하면 exe 옆에 설정 파일이 생깁니다.
  wiz_overlay_settings.json(경로), wiz_dosbox.conf(DOSBox 실행 설정),
  wiz1_explored.json(지도 탐색 기록). 오류가 나면 wiz_overlay_error.log가 생깁니다.
- 서명되지 않은 실행 파일이라 Windows SmartScreen이 경고할 수 있습니다.
  "추가 정보 → 실행"을 누르면 됩니다.

저작권
------
- Wizardry는 해당 권리자의 상표이며, 게임과 그 내용(문장, 지도, 그림)의 저작권은
  권리자에게 있습니다. 이 프로그램은 무료로 배포하는 비공식 팬 제작물입니다.
- 게임 파일과 지도 데이터는 들어 있지 않습니다. 지도와 아이템 정보는 실행할 때
  사용자의 게임 디스크(WIZ1.DSK 등)에서 읽습니다. 화면 문장(네 낱말 이상)은 원문 대신
  원문의 해시값으로 찾아 한글로 바꿉니다. 짧은 메뉴 낱말과 몬스터·아이템 이름은 화면
  글자와 맞추려고 영문을 그대로 담고 있습니다.
- 권리자의 요청이 있으면 배포를 즉시 중단합니다.
